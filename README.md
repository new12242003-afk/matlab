# Mini Project v2: วัดมุมจากรูป (MATLAB)

เปิดรูปแล้วคลิก 3 จุด คือจุดยอดมุมและปลายแขนทั้งสองข้าง โปรแกรมจะคำนวณมุมเป็นองศา วาดเส้นกับส่วนโค้งกำกับ และวัดหลายมุมต่อกันในรูปเดียวได้
ใช้แค่ MATLAB พื้นฐาน ไม่ต้องมี Toolbox ใช้กับ MATLAB Online ได้

## วิธีใช้ (พิมพ์ที่ Command Window)
```matlab
measure_angle('photo.jpg')      % วัดกี่มุมก็ได้ กด Enter เพื่อจบ
measure_angle('photo.jpg', 2)   % วัด 2 มุมแล้วจบ
measure_angle                   % เปิดหน้าต่างเลือกไฟล์
demo_measure_angle              % ทดสอบกับสามเหลี่ยมจำลองที่รู้มุมจริง (40°, 65°, 75°)
```
แต่ละมุมให้คลิก: **1) จุดยอดมุม → 2) ปลายแขนข้างที่ 1 → 3) ปลายแขนข้างที่ 2**

## เวอร์ชันเว็บ (ไม่ต้องมี MATLAB)
โฟลเดอร์ `web/` เป็นเว็บไซต์ให้ใครก็ได้อัปโหลดรูปแล้ววัดมุมในเบราว์เซอร์ ใช้สูตรเดียวกับ `angle_from_points.m` รูปไม่ถูกส่งออกจากเครื่องผู้ใช้
- เลือกรูป ลากมาวาง หรือวางจากคลิปบอร์ด (Ctrl+V) ใช้กับมือถือได้
- ซูม/เลื่อนภาพ มีแว่นขยายช่วยเล็ง ลากจุดเพื่อปรับตำแหน่งได้ คลิกบนจุดเดิมเพื่อใช้จุดร่วมกัน
- บันทึกรูปพร้อมผลเป็น PNG และดาวน์โหลดตารางผลเป็น CSV
- ปุ่ม "ลองกับภาพตัวอย่าง" ใช้สามเหลี่ยม 40°, 65°, 75° แบบเดียวกับ `demo_measure_angle` แล้วแสดงความคลาดเคลื่อน

```bash
npx serve web                      # รันในเครื่อง (ต้องเปิดผ่าน http เพราะใช้ ES module)
node --test web/angle.test.mjs     # ทดสอบแกนคำนวณ
```

### Deploy บน Railway
ไฟล์ `Staticfile` ที่รากโปรเจกต์บอก Railway ให้เสิร์ฟโฟลเดอร์ `web/` เป็นเว็บ static (Caddy) ไม่ต้องตั้งค่าอะไรเพิ่ม
1. ที่ [railway.com](https://railway.com) กด **New Project → Deploy from GitHub repo** แล้วเลือก repo นี้
2. เมื่อ deploy เสร็จ ไปที่ **Settings → Networking → Generate Domain** เพื่อรับลิงก์ `*.up.railway.app`
3. หลังจากนั้นทุกครั้งที่ push ขึ้น GitHub ระบบจะ deploy ใหม่ให้อัตโนมัติ

### Deploy บน Vercel
ไฟล์ `vercel.json` ที่รากโปรเจกต์ตั้ง `outputDirectory` เป็น `web` (ถ้าไม่มี Vercel จะเสิร์ฟรากโปรเจกต์ซึ่งไม่มี `index.html` แล้วขึ้น 404) import repo นี้ที่ [vercel.com/new](https://vercel.com/new) ได้เลยโดยไม่ต้องตั้ง Root Directory

## หลักการคำนวณ
ให้ V เป็นจุดยอด และ P1, P2 เป็นปลายแขน สร้างเวกเตอร์ u = P1 − V และ v = P2 − V

- ผลคูณจุด: u·v = |u||v| cos θ
- ผลคูณไขว้: |u×v| = |u||v| sin θ
- θ = atan2(|u×v|, u·v)

ใช้ `atan2` แทน `acos(u·v / |u||v|)` เพราะแม่นยำกว่าเมื่อมุมใกล้ 0° หรือ 180°
ภาพทดสอบใช้กฎของไซน์หาตำแหน่งจุดยอด C จากมุม A และ B ที่กำหนด

## ไอเดียต่อยอด
- หาเส้นอัตโนมัติด้วย Hough Transform (เขียนเอง หรือใช้ `hough` ใน Toolbox) แล้ววัดมุมโดยไม่ต้องคลิก
- วัดความคลาดเคลื่อนจากการคลิกหลายครั้ง แล้วหาค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน
- วัดความยาวด้วย (ต้องรู้สเกล พิกเซลต่อเซนติเมตร)
- ใช้งานจริง เช่น วัดมุมเอียงของหลังคา มุมข้อศอกตอนออกกำลังกาย หรือมุมของเงาเพื่อหามุมดวงอาทิตย์
